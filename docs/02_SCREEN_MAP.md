## 2. 공통 내비게이션

### 고객 헤더

- 제공받은 `Zabre` 이미지 로고: 홈으로 이동하며 모바일에서는 액션 아이콘과 겹치지 않게 축소
- 동물·카테고리·브랜드 메뉴: 상품 목록으로 이동
- 기획전: 기획전 목록으로 이동
- 검색: 상품 목록의 `q` 검색으로 이동
- 계정: 비로그인 시 로그인, 로그인 시 마이페이지로 이동
- 비로그인 헤더: 로그인 진입만 표시하고 찜·장바구니·내 정보 아이콘은 숨김
- 고객 로그인 헤더: 장바구니 아이콘과 사람 아이콘 메뉴에서 내 정보·찜·주문으로 이동
- 관리자 로그인 헤더: 사람 아이콘 메뉴에서 관리자 페이지로 이동하며 고객 장바구니·찜을 표시하지 않음

모바일에서는 헤더 아래에 강아지용품·고양이용품·전체상품·기획전 카테고리 줄을 항상 제공한다. 검색과 로그인 후 장바구니·계정 진입은 한두 번의 탭 안에 제공한다.

### 관리자 내비게이션

- 대시보드
- 상품 관리
- 홈 섹션 관리
- 주문 관리
- 쇼핑몰 보기
- 로그아웃

관리자 메뉴가 숨겨져 있더라도 URL 직접 접근과 API 요청은 권한 검사로 차단한다.

### 3.1 홈 화면 상세

| 순서 | 섹션 | 필수 내용 | 이동 대상 |
|---|---|---|---|
| 1 | 공지 바 + 헤더 | 배송·프로모션 안내, 로고, 메뉴, 계정, 찜, 장바구니 | 메뉴별 고객 화면 |
| 2 | 히어로 슬라이드 | 최대 3장, 제목, 짧은 설명, CTA, 순서 표시와 수동 전환 | 기획전·상품·콘텐츠 |
| 3 | 상황별 기획전 | 최소 2개 테마 카드 | 기획전 상세 |
| 4 | 인기·신상품 | 상품 이미지, 브랜드, 이름, 가격, 상태, 찜 | 상품 상세 또는 장바구니 |
| 5 | 동물·카테고리·브랜드 | 초기 강아지·고양이와 주요 분류 | 필터가 적용된 상품 목록 |
| 6 | 공간 중심 콘텐츠 | 펫룸·인테리어 비주얼, 설명, 관련 상품 | 기획전·상품·콘텐츠 |
| 7 | 서비스 안내 + 푸터 | 배송·교환·반품, 약관, 개인정보, 사업자 정보 | 정책 화면 |

홈 자동 슬라이드는 사용자가 직접 멈추거나 조작할 수 있게 하며, 모바일에서 CTA와 텍스트가 이미지 밖으로 잘리지 않아야 한다.

### 3.2 상품 카드 공통 요소

- 대표 이미지와 이미지 대체 텍스트
- 브랜드명, 상품명
- 정상가와 판매가
- 품절 또는 판매 종료 상태
- 찜 추가·해제
- 상품 상세 이동
- 빠른 장바구니는 옵션이 하나일 때만 허용하거나, 옵션 선택 UI를 먼저 연다.

### 3.3 상품 상세 필수 상태

- 기본: 판매 중이며 옵션 선택 전
- 옵션 선택 완료: 가격과 재고가 확정된 상태
- 품절: 구매 버튼 비활성화와 명확한 안내
- 판매 종료·숨김: 일반 고객이 구매할 수 없는 상태
- 이미지 없음: 대체 이미지 표시
- 로딩·오류: 중복 클릭 방지, 재시도 또는 목록 복귀 제공

모바일에서는 선택 옵션, 수량, 가격, 장바구니 또는 구매 버튼을 하단 고정 영역으로 제공할 수 있다.

### 3.4 장바구니·주문서 필수 상태

- 장바구니 비어 있음
- 정상 구매 가능
- 담은 뒤 가격이 변경됨
- 옵션이 품절 또는 판매 중단됨
- 요청 수량이 현재 재고를 초과함
- 배송지 또는 동의 항목 입력 오류
- 결제 요청 중, 성공, 사용자 취소, 승인 실패

가격과 재고 변화는 주문서 진입 및 결제 승인 전에 서버에서 다시 확인한다.

### 4.1 상품 등록·수정 폼 구성

1. 기본 정보: 상품명, 슬러그, 요약, 상세 설명
2. 분류: 동물 종, 브랜드, 카테고리
3. 판매 정보: 판매 상태, 노출 상태
4. 옵션·재고: 옵션명, 옵션값, SKU, 가격, 재고
5. 미디어: PC 파일 선택기 또는 모바일 사진 선택기로 이미지 선택, 다중 업로드, 미리보기, 대체 텍스트, 대표 이미지와 노출 순서 지정, 개별 실패 재시도
6. 전시 연결: 인기·신상품 여부 또는 홈 섹션 연결

저장 실패 시 입력값을 보존하고 어떤 항목을 수정해야 하는지 표시한다. 삭제는 되돌리기 어려운 동작이므로 상품명과 삭제 결과를 알리는 확인 단계를 거친다. `PUBLISHED` 상품이면 먼저 숨김·판매 종료하도록 안내하고, 홈 `PRODUCT` 직접 연결이 있으면 연결 해제를 안내한다. 주문 이력이 있으면 기존 주문 상세가 보존되고 현재 상품 연결만 분리된다는 두 번째 확인을 요구한다. 활성 재고 예약이 있거나 다른 관리자가 먼저 수정한 오래된 `version`이면 삭제하지 않고 상태 확인·새로고침을 안내한다.

업로드 형식은 JPEG·PNG·WebP로 제한한다. 휴대폰 사진이 HEIC/HEIF로만 제공되면 현재는 자동 변환하지 않고 지원 형식으로 내보낸 뒤 다시 선택하도록 안내한다. 이미 서버에 존재하는 신뢰 가능한 `storageKey`를 연결하는 보조 입력은 접힌 고급 영역에만 유지한다.

### 4.2 기획전·홈 관리 원칙

- 기획전은 제목, 설명, 대표 이미지, 연결 상품, 공개 상태, 노출 순서를 가진다.
- 현재 관리 화면은 홈 섹션과 히어로만 편집하며, 기획전 관리 화면과 API는 Later다.
- 홈 히어로는 최대 3장만 공개할 수 있게 제한한다.
- 홈 섹션은 정해진 슬롯을 수정하며 자유형 페이지 빌더를 제공하지 않는다.
- 연결 대상이 숨김·판매 종료된 경우 고객 화면에서 구매 가능한 상품만 노출한다.

### 4.3 주문 상태 예시

```text
결제 대기 → 결제 완료 → 상품 준비 → 배송 중 → 배송 완료
     └────→ 결제 실패
결제 완료 이후 → 취소 요청/취소 완료  (MVP에서는 수동 상태 표시 가능)
```

임의의 역방향 변경이나 결제되지 않은 주문의 배송 처리는 허용하지 않는다. 실제 취소·환불 API 자동화는 Later 범위다.

## 5. 핵심 사용자 플로우

### 5.1 상품 탐색에서 장바구니까지

```text
홈
→ 상황별 기획전 또는 인기·신상품 선택
→ 기획전 상세 또는 상품 목록
→ 상품 상세
→ 옵션·수량 선택
→ 장바구니 담기
→ 장바구니
```

완료 조건:

- 선택한 상품, 옵션, 수량이 동일하게 장바구니에 표시된다.
- 새로고침 후에도 장바구니 데이터가 유지된다.
- 품절 옵션은 담기와 수량 증가가 차단된다.

### 5.2 회원가입 후 회원 주문

```text
장바구니
→ 주문하기
→ 로그인 또는 회원가입
→ 회원가입 완료 및 로그인
→ 원래 주문 흐름으로 복귀
→ 주문서 작성
→ 테스트 결제
→ 서버 결제 검증
→ 주문 완료
→ 마이페이지 주문 내역
```

완료 조건:

- 신규 회원가입 계정은 이전 방문자 장바구니·과거 방문자 찜을 승계하지 않고 빈 상태로 시작한다.
- 주문 완료 정보와 마이페이지·관리자 주문 정보가 일치한다.
- 결제 실패 시 성공 주문으로 표시되지 않고 재시도 경로를 제공한다.

### 5.3 기존 회원 주문

```text
로그인
→ 상품 상세
→ 바로 구매 또는 장바구니
→ 주문서
→ 테스트 결제
→ 주문 완료
→ 회원 주문 상세
```

완료 조건:

- 로그인 성공 후 사용자가 시작한 화면 또는 주문 흐름으로 돌아온다.
- 본인이 아닌 다른 회원의 주문 상세에는 접근할 수 없다.

### 5.4 비회원 주문과 조회

```text
장바구니
→ 주문하기
→ 비회원 주문 선택
→ 구매자·배송지·비회원 조회 정보 입력
→ 테스트 결제
→ 주문 완료 및 주문번호 확인
→ 비회원 주문 조회
→ 주문번호 + 검증 정보 입력
→ 비회원 주문 상세
```

완료 조건:

- 계정을 만들지 않고 주문 완료까지 진행할 수 있다.
- 주문번호만 아는 제3자가 주문을 조회할 수 없다.
- 비회원 주문의 구매자·배송지·상품 스냅샷이 관리자 주문 상세에 동일하게 표시된다.

### 5.5 찜과 로그인

```text
비로그인 상품 상세
→ 찜 대신 로그인 안내
→ 로그인 또는 회원가입
→ 원래 상품 상세로 복귀
→ 회원 찜 추가·목록 확인
```

방문자 장바구니 병합은 기존 고객 로그인에서만 Must 범위다. 로그인 전에 담은 상품은 같은 옵션 수량을 서버 규칙으로 안전하게 합친다. 신규 회원가입은 방문자 데이터를 승계하지 않고 빈 상태로 시작한다. 비회원 찜 API는 `401`, 관리자 찜 API는 `403`으로 차단한다.

### 5.6 관리자 상품·홈 운영

```text
관리자 로그인
→ 상품 등록 또는 수정
→ PC 파일 또는 모바일 갤러리에서 이미지 선택
→ 서버 검증과 업로드 완료 후 반환된 `storageKey`를 옵션·재고·이미지 메타데이터와 저장
→ 공개
→ 홈 섹션 또는 히어로 연결 정보 수정
→ 고객 홈에서 노출 확인

또는 상품 수정 화면의 별도 위험 영역에서 삭제 선택
→ 상품명과 영구 삭제 경고 확인
→ 서버가 ADMIN·CSRF·version·판매 상태·주문 이력·홈 직접 연결을 재검사
→ 주문 이력이 있으면 과거 주문 스냅샷 보존과 현재 상품 연결 해제를 별도로 확인
→ 활성 재고 예약이 있으면 주문 처리 완료 전까지 삭제 중단
→ 허용되면 상품 종속 DB 데이터를 트랜잭션으로 삭제하고 목록으로 이동
```

완료 조건:

- 고객 화면에 저장된 상품명, 가격, 이미지, 판매 상태가 반영된다.
- 선택한 파일은 업로드 전 미리보기로 확인할 수 있고 업로드 중에는 중복 제출을 막으며, 형식·용량·해상도 오류는 해당 이미지 가까이에 표시한다.
- 업로드된 이미지의 첫 순서를 대표 이미지로 사용하고 키보드와 터치 환경 모두에서 순서를 바꿀 수 있다.
- 숨김 또는 판매 종료 상품은 새 주문에 사용할 수 없다.
- 공개 기획전은 seed 데이터와 공개 API에서 구매 가능한 상품만 노출한다.
- 삭제된 상품은 관리자 목록·고객 목록·찜·장바구니·기획전 연결에서 사라지고, 업로드 이미지 파일은 즉시 지우지 않는다. 과거 주문 상세는 상품명·브랜드·SKU·옵션·가격·이미지 스냅샷으로 계속 표시한다.
- 삭제가 거절되면 공개 상품은 숨김·판매 종료, 홈 직접 연결 상품은 해당 연결 해제, 활성 재고 예약 상품은 주문 결제·만료 처리 완료처럼 관리자가 다음에 할 일을 화면에 표시한다.

### 5.7 관리자 주문 처리

```text
관리자 주문 목록
→ 주문번호 또는 구매자 검색
→ 주문 상세
→ 결제 상태와 주문 스냅샷 확인
→ 허용된 주문 상태 변경
→ 고객 주문 상세에서 상태 확인
```

완료 조건:

- 회원·비회원 주문을 구분해 조회할 수 있다.
- 허용되지 않은 상태 변경은 서버에서 거절한다.
- 상태 변경 후 고객 화면과 관리자 목록이 일관된다.

## 7. 공통 화면 상태와 오류 처리

모든 목록·상세·폼 화면은 다음 상태를 고려한다.

- 로딩: 스켈레톤 또는 진행 표시, 중복 제출 차단
- 비어 있음: 원인과 다음 이동 경로 제공
- 검증 오류: 문제가 있는 필드 가까이에 한국어 안내
- 네트워크 오류: 재시도와 안전한 복귀 경로 제공
- 인증 만료: 로그인 이동 후 가능한 경우 원래 위치로 복귀
- 권한 없음: 관리자·타인 주문 정보 노출 없이 안내
- 존재하지 않음: 홈 또는 목록으로 이동할 수 있는 404 화면
- 재고·가격 충돌: 최신 정보 표시 후 주문 금액 재확인

## 8. 반응형 확인 기준

최소 아래 대표 환경에서 핵심 플로우를 확인한다.

- 모바일: 좁은 화면에서 강아지·고양이 카테고리 줄, 단일 배너형 슬라이드와 좌우 스와이프, 옵션 선택, 하단 구매 버튼, 주문 폼
- 태블릿: 상품 그리드와 상품 상세 2열 전환
- 데스크톱: 최대 콘텐츠 폭, 관리자 표, 긴 주문 정보

모바일에서 상품 목록은 이미지 비율을 일관되게 유지하고, 주문 버튼과 결제 동의 영역이 키보드에 가려지지 않게 한다. 관리자는 데스크톱을 우선하되 태블릿에서도 주문 조회와 상태 변경이 가능해야 한다. 관리자 이미지 입력은 별도 폴더 업로더가 아니라 하나의 `accept="image/jpeg,image/png,image/webp"` 파일 입력을 사용해 데스크톱에서는 파일 선택기, 모바일에서는 사진 선택기를 열며 카메라 강제 `capture`는 사용하지 않는다.

## 9. 5분 데모 시나리오

### 사전 준비

- 관리자 계정 1개와 일반 회원 계정 1개
- 강아지·고양이 상품 각각 포함, 옵션·재고가 있는 상품 최소 8개
- 품절 옵션이 있는 상품 1개
- 상황별 기획전 2개
- 히어로 배너 최대 3개
- 관리자 업로드 검증용 JPEG·PNG·WebP 상품 이미지
- 테스트 결제 정상·실패 절차
- 비회원 조회에 사용할 완료 주문 1개

### 진행 순서

1. **홈 경험**: 히어로 슬라이드, 상황별 기획전, 인기·신상품, 공간 콘텐츠를 빠르게 보여준다.
2. **상품 경험**: 기획전에서 상품 상세로 이동하고 옵션을 선택해 찜과 장바구니에 담는다.
3. **비회원 구매**: 장바구니에서 비회원 주문서를 작성하고 테스트 결제를 완료한다.
4. **비회원 조회**: 주문번호와 검증 정보로 방금 생성한 주문을 조회한다.
5. **회원 경험**: 로그인하고 마이페이지 주문 내역과 찜 목록을 보여준다.
6. **관리자 경험**: 관리자에서 방금 생성된 주문과 결제 상태를 확인하고 주문 상태를 변경한다.
7. **운영 경험**: 상품 가격 또는 홈 기획전 연결을 수정한 뒤 고객 화면에 반영되는 것을 보여준다.

### 데모 중단 조건

아래 문제가 있으면 시연 준비 완료로 보지 않는다.

- 회원 또는 비회원 중 하나라도 결제 완료까지 진행되지 않음
- 결제 성공 화면은 보이지만 DB나 관리자에 주문이 없음
- 다른 회원 또는 검증되지 않은 비회원이 주문 상세를 조회할 수 있음
- 관리자 수정 사항이 고객 화면에 반영되지 않음
- 모바일에서 핵심 CTA가 보이지 않거나 주문 폼을 제출할 수 없음
- 품절 상품이 주문되거나 브라우저가 보낸 금액으로 결제가 승인됨

## 10. 화면 확정 전 확인 목록

- 브랜드명, 로고, 기본 색상과 서체
- 상품 카드에 표시할 정상가·할인가 정책
- 배송비와 무료 배송 기준
- 필수 회원가입 항목과 필수 약관 문구
- 비회원 주문 조회 검증 조합
- 테스트 결제 제공사와 성공·실패 콜백 규격
- 주문 상태명과 관리자가 바꿀 수 있는 범위
- 상품 옵션 형태와 재고 차감 시점
- 이미지 권장 비율과 최대 업로드 크기
- 시연용 배송·교환·반품 정책 및 사업자 표시 정보
